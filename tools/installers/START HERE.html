⚠ ይህን ገጽ ዚፑን ሳይከፍቱ (Extract ሳያደርጉ) እያዩት ከሆነ፦ ዚፕ ፋይሉ ላይ Right-click → Extract All → Extract፣ ከዚያ በወጣው ፎልደር ውስጥ ይቀጥሉ።
Seeing this inside the zip? Right-click the zip → Extract All → Extract, then continue in the extracted folder.

ለመጫን · To install

  1. Premiere Pro እና After Effects ን ሙሉ በሙሉ ይዝጉ (File → Exit)።
    Fully quit Premiere Pro and After Effects (File → Exit).
  2. በዚህ ፎልደር ውስጥ Install.cmd (Windows) ወይም Install.command (Mac) ሁለቴ ይጫኑ፣ ማንኛውንም ቁልፍ ይጫኑ፣ INSTALLATION SUCCESSFUL እስኪል ይጠብቁ።
    Double-click Install.cmd (Windows) or Install.command (Mac) in this folder, press any key, and wait for INSTALLATION SUCCESSFUL.
  3. Premiere ን ይክፈቱ፣ ፕሮጀክት ይክፈቱ፣ ከዚያ Window → Extensions → Amharic Captions Pro።
    Open Premiere, open a project, then Window → Extensions → Amharic Captions Pro. (After Effects: the same menu.)
  4. የመጀመሪያ ጊዜ ብቻ፦ በፓነሉ ላይ «የአማርኛ ሞዴሉን አውርድ» ን አንድ ጊዜ ይጫኑ (610 MB ገደማ)። ኢንተርኔት ቢቋረጥ ካቆመበት ይቀጥላል።
    First time only: press “Download the Amharic model” in the panel once (about 610 MB). If the internet drops, it continues where it stopped.
